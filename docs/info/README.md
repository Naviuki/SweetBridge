# Материалы по проекту

|------|------------|
| `01-presentation-sweetbridge.pptx` | Презентация проекта: 12 слайдов, суть маркетплейса, волны, роли, цифры. |
| `02-design-report.pptx` | Отчёт по дизайн-системе: 12 слайдов, токены, шрифты, брейкпоинты, результаты Lighthouse. |

## Как открыть

Презентации — PowerPoint, LibreOffice Impress или любой просмотрщик OOXML.
Ролик — любой видеоплеер; либо в браузере:

```html
<video controls src="/docs/info/04-promo-716-team.mp4"></video>
```

В веб-приложении эти файлы не раздаются: папка `docs/` служит только для хранения материалов,
статикой отдаётся исключительно `wwwroot`.
