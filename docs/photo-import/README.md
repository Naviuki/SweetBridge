# Импорт фотографий каталога

Витрина «Сладкого моста» наполнена реальными фотографиями кондитерских изделий
с партнёрского производства (https://yhkhleb.ru/production/).

## Как это сделано

1. `tools/import-product-photos.ps1` обходит страницы категорий партнёра, читает из карточки
   название изделия (`data-name`) и ссылку на снимок (`data-gallery`, при отсутствии — `img src`),
   скачивает файлы в `src/SweetBridge.Web/wwwroot/images/products` и сохраняет выгрузку
   в `source-catalog.json`. Между запросами ставится пауза, чтобы не нагружать сайт партнёра.
2. `tools/resize-product-photos.ps1` уменьшает снимки до 1200 px по ширине и пережимает их в JPEG
   (качество 85): исходные файлы весили 352 МБ, после обработки — 11,4 МБ.
3. Из 91 снимка оставлено 20 — по одному на каждую позицию каталога. Соответствие зафиксировано
   в `product-mapping.md` и прописано в колонке `photo` файла
   `src/SweetBridge.Web/Infrastructure/Seeding/Data/catalog.csv`.
4. `CatalogSeeder` при каждом старте сверяет пути к фотографиям и обновляет их у уже созданных
   товаров (`Product.UpdatePhoto`), поэтому замена снимка подхватывается без пересоздания базы.

## Как соответствие выбиралось

Позиции каталога демонстрационные («Шоколад „Алыа“», «Карамель „Балык“»), изделия партнёра —
реальные и называются иначе. Поэтому снимок подбирался **по типу изделия**, а не по названию:
конфеты — к конфетам, овсяное печенье — к печенью с фруктами, пряник — к пряникам и так далее.

Полное соответствие: [product-mapping.md](product-mapping.md).

## Что нужно учитывать при публикации

- Фотографии показывают упаковку партнёра с его названием («ЯХК», «Туймаада»). Названия товаров
  в каталоге демонстрационные, поэтому фотография и название не совпадают — перед публикацией
  либо заменить демонстрационные названия на реальный ассортимент, либо заменить снимки на
  собственные.
- Фотографии используются **с разрешения владельца партнёрского сайта**. Обход каталога идёт с
  паузами; при отказе от использования достаточно удалить папку `wwwroot/images/products`
  и очистить колонку `photo` в `catalog.csv` — сайт вернётся к заглушке.
- Формат файлов — JPEG до 1200 px, суммарно около 2,5 МБ.

## Повторный импорт

```powershell
powershell -ExecutionPolicy Bypass -File tools/import-product-photos.ps1
powershell -ExecutionPolicy Bypass -File tools/resize-product-photos.ps1 -MaxWidth 1200 -Quality 85
```

Скрипты идемпотентны: уже скачанные файлы повторно не загружаются, уменьшенные — не трогаются.
