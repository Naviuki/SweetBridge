# Лицензии шрифтов

В `wwwroot/fonts` лежат файлы шрифтов, скачанные из пакета `@fontsource`
(репозиторий <https://github.com/fontsource/fontsource>).

- **Unbounded** — SIL Open Font License 1.1
- **Manrope** — SIL Open Font License 1.1

Обе лицензии допускают использование, изменение и распространение, в том числе в вебе,
при условии сохранения уведомления об авторских правах. Текст лицензии:
<https://openfontlicense.org>.

Подключение локальное (``@font-face`` в ``wwwroot/css/fonts.css``), внешние CDN запрещены
политикой безопасности ``font-src 'self'``.
